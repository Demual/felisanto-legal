Licencias de código abierto y datos

Llicències de codi obert i dades · FeliSanto (com.jrsoft.felisanto) · 11 de noviembre de 2026

FeliSanto está hecho con estas bibliotecas de código abierto, a cuyos autores agradecemos su trabajo, y con una base de datos del santoral propia. Dentro de la aplicación, en Ajustes → Licencias de código abierto, están el texto entero de la licencia de cada paquete de Flutter y Dart, el de la licencia Apache de AndroidX y Kotlin, y la nota sobre los datos del santoral.

FeliSanto està fet amb aquestes biblioteques de codi obert i amb una base de dades del santoral pròpia. El text sencer de cada llicència és a l’aplicació: Configuració → Llicències de codi obert.

Los datos del santoral

El santoral de FeliSanto es una base de datos propia de JR Soft, que va dentro de la aplicación y se consulta sin conexión.

Les dades del santoral són una base pròpia de JR Soft amb fets de Wikidata (CC0 1.0), contrastats amb romcal (MIT), que no va dins de l’aplicació, i amb el Calendari Romà General. Les línies que descriuen cada sant les escriu JR Soft.
